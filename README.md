# Sentiment Analysis Project

This is a **Flask-based web application** that predicts the **sentiment** of a given text review using a trained machine learning model.

## Features
- Logistic Regression model is trained on IMDB dataset.
  - Dataset - https://paperswithcode.com/dataset/imdb-movie-reviews
- Web application is created using HTML and CSS
- Backend is conected by FLASK application
- User can enter a movie review on the web page and get the result whether the review ia positive or negative
